# 德语 A1 大纲说明

> 机器可读的大纲在 `de.json`(词条总登记处),角色表在 `../languages/de.json` 的 `cast`。

## 故事线

20 岁的成都男生**王伟**(Wei Wang)九月到柏林读计算机,德语从零开始。课程跟着他在德国的第一年走:迎新周认识学伴莉娜,德语班认识意大利同学索菲娅(第 1–2 单元,9 月)→ 搬进约纳斯和索菲娅的 WG,认识楼下的霍夫曼先生(第 3 单元,10 月)→ 超市、咖啡馆、面包店、约纳斯掌勺的餐馆(第 4 单元)→ 冬季学期开学、约看电影、约纳斯的生日派对(第 5 单元,10–11 月)→ 逛柏林、坐火车去约纳斯的老家汉堡(第 6 单元,12 月)→ 买冬衣、开银行账户、给家里寄春节礼物、打电话报名德语考试(第 7 单元,1–3 月)→ 踢球淋雨感冒、看医生、湖边的周末,七月考完 A1,写下《我在德国的第一年》(第 8 单元,3–7 月)。学习者和他同步:每一课都在德国完成一件具体的小事。

## 给写课同事的注意事项

1. **新词和大纲一致**(校验会查):想加词、换词,先改大纲再写课,并告诉负责人。同一个词只教一次,后面的课放进 `reviewItems`。
2. **只用学过的词**,`line.items` 要列全(复习词尤其要列)。下面这些不单立词条,直接用,items 标对应的词条:
   - 冠词、变格和变位形式:der / die / das / den / dem 跟着名词走;bin / bist / ist → `de.sein`,meine / einen / keinen → `de.mein` / `de.ein` / `de.kein`;war / hatte(第 8 单元)→ `de.sein` / `de.haben`,过去分词 → 原动词。
   - kommen、heißen 只有短语词条:du kommst、er heißt 标 `de.ich_komme_aus` / `de.ich_heisse`;aus 只用在 aus + 地名里。
   - 按规则组成的数(vierzehn、achtzig、einundzwanzig、vierhundertfünfzig):对应的数字课之后可以直接用,标组成它的数字词条。
   - 人名、地名(Berlin、Kreuzberg、Neukölln、Hamburg、Potsdam、Köln、Chengdu、Shanghai)。国家只用学过的 China / Deutschland / Italien。
   - 其他虚词都要先教再用:mit 从 u4.l02 起,zu / an 从 u6.l02 起,für / von / bis 从 u7.l04 起;nicht 从 u3.l03 起(在那之前不能说 Ich verstehe nicht);Entschuldigung 从 u6.l03 起。
3. **课文里不能有错的德语句子**:练习会直接拿课文出排序题和跟读题。王伟说错的地方用对方的纠正或中文说明来体现,课文只放正确的句子。
4. **校验的硬性要求**:课文 4 句以上至少 2 道理解题;reading 至少 6 句;A1 每句不超过 15 个词;reading 的说话人用 `wei`(第一人称)或 `narrator`。每课 `scenarioZh` 末尾列了建议的说话人。
5. **标准德语(德国)**:新正字法(dass、bisschen、Tschüss);Schrippe、Sonnabend、Juno / Julei 只写在注释里当知识,课文用 Brötchen、Samstag、Juni / Juli。
6. **真实但不落地**:城市、区名、车站名可以用;学校、超市、银行、语言学校、考试机构不出现真实名字;地址用 Musterstraße 这类示例,电话号码不要照抄真实号码。
7. **du / Sie 不能乱**:照角色表的“称呼”一列;服务类角色和王伟互相用 Sie。
8. **特别注意的课**
   - u1.l03:回答 Wie geht's? 后反问 Und dir?,不是 Und du?。
   - u2.l01:只有 0–9,手机号一位一位地读;“手机”u2.l02 才教。u2.l03:年龄只到 20,13–19 按规则用。
   - u3.l03:kein 和 nicht 要成对对比;er / sie / es 指物(Der Tisch? Er ist neu.)。u3.l04:“个位在前”要设计听辨对比(45 / 54、450 / 540)。
   - u4.l02:möchten 第三人称没有 -t;Café 和 Kaffee 的重音。u4.l05:小费只写“凑个整数”,不写比例。
   - u5.l01:halb neun = 8:30,理解题考这个。u5.l03:要有前缀放句末的句子;frühstücken 不可分。u5.l04:ich will 不是“我将要”;nicht müssen = 不必。
   - **月份分两次教**:9–2 月在 u5.l05,3–8 月在 u7.l05;季节 Herbst / Winter 在 u5.l05,Frühling / Sommer 在 u8.l02。之前的课别用还没教的月份和季节。
   - u5.l08:生日祝福只在当天说(德国习俗)。u6.l02:第三格只用 dem / der 的固定搭配(mit dem Bus、zur Uni、an der Haltestelle),不展开变格表。u6.l04、u6.l05:广播句子短、信息全(站台、时间、晚点几分钟)。
   - u7.l02:ihn / sie / es 指衣服。u7.l03:中文名字的顺序和拼读(Name: Wang, Vorname: Wei)。
   - u8.l04:只写感冒这类轻症,不写药名,不做医疗建议。u8.l05:完成时只用学过的动词,用到的过去分词在语法说明里列出来。
9. 第 1、2 课在大纲里原样保留,只补了场景和语法重点;第 2 课 `estimatedMinutes` 是 7(其余课 8–12),以后改那节课时可以顺手调整。

## 和最初建议不同的地方

- **数字**:已写好的第 2 课(家人)占了第 1 单元的位置,所以数字 0–20 挪到第 2 单元(u2.l01 报电话号码、u2.l03 年龄),20–1000 在第 3 单元(房租);第 1 单元改为多练“听不懂怎么办”(Wie bitte? / langsam / noch einmal)。
- **月份和季节**:一课最多 10 个新词,12 个月放不进一课,按故事的时间分两次教(见上)。
- **课号和顺序**:复习课 id 用 l08,order 按 id 算,和已写好的两课、英语和法语大纲保持一致。
- **只有复数的名词**(die Eltern、die Geschwister、die Ferien):schema 的 gender 没有“复数”这一项,暂标 f 才能通过冠词检查,`noteZh` 里说明 die 是复数冠词。月份和不可数名词(Milch、Geld、Wetter …)的复数写 "-"。
- **不单立词条**:kommen / heißen(第 1 课已有短语)、war / hatte 和过去分词(当变位形式用)。
