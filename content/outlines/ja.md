# 日语 A1 大纲说明

> 机器可读的大纲按单元分成 8 个文件:`ja/a1u1.json` … `ja/a1u8.json`(词条总登记处,校验工具会自动合并);角色表在 `../languages/ja.json` 的 `cast`。
> 范围:A1 前 8 个单元 × 6 课 = 48 课,423 个词条(其中假名字符 97 个)。每单元 l01–l05 是新课,**l08 是“单元复习与应用”**(按顺序是本单元第 6 课,l06、l07 留给以后扩充);`order` 按 id 计算(101010 … 108080),和英语、法语、德语大纲一致。下文用 `u3.l04` 代表 `ja.a1u3.l04`。

## 故事线

20 岁的杭州女生**林雨**(リン・ユー)3 月底来到东京,在大学的留学生别科(日语预科)从零学日语,明年 4 月升入经济学部。课程跟着她在东京的头四个月走:学伴佐藤咲到羽田机场接她,她住进大家さん小林春子的合租房,认识韩国室友金智友(第 1 单元,3 月底)→ 别科开学、田中老师的第一课、欢迎会上做自我介绍、认识咲的高中同学健太(第 2 单元,4 月初)→ 给大家さん看家人照片、办手机号、交朋友、写作文《我的家人》(第 3 单元,4 月)→ 便利店、面包店、大学食堂、大家さん的晚饭、家庭餐厅、教大家包饺子(第 4 单元,4–5 月)→ 作息、喫茶店打工面试、智友的生日、约看电影、第一天打工(第 5 单元,5 月)→ 在新宿找厕所、看街区地图、去交番问路、和健太坐地铁去浅草、在车站等朋友(第 6 单元,5–6 月)→ 梅雨季买伞、买 T 恤和鞋、给妈妈挑礼物、结账、逛百元店(第 7 单元,6 月)→ 合租房的早晚、我的一天、上周末、爱好、去海边写日记、写短文回顾第一学期(第 8 单元,7 月)。每一课都在东京完成一件具体的小事,学习者和她同步进步。

## 假名和汉字的安排

- **平假名**(u1.l01–l05)每课 10 个:清音 46 个按五十音顺序,另有 4 个“代表字”词条:が(浊音)、ぱ(半浊音)、きゃ(拗音)、っ(促音)。其余浊音、拗音以及长音、ぢ / づ 按规则讲(grammarFocusZh 和词条 noteZh 里写清),不单立词条。**片假名**(u2.l01–l05)46 个加长音符 ー;外来语的特殊拼法(ティ 等)借 パーティー 一词讲。字符词条的 zh 以罗马音开头(就是“选意思”题的选项),`features.roman` 是输入法的打法(を = wo、ん = n、っ = xtsu、ー = -);noteZh 写字源(あ←安、カ←加)和易混字(さ / ち、ぬ / め、シ / ツ、ソ / ン)。
- 问候语在第 1 单元先整体记(词条带罗马音),到 u1.l05 学完全部平假名就都能自己拼读;第 2 单元的片假名认读靠人名、国名(リン・ユー、タイ),外来语词条从第 4 单元起大量出现(コンビニ、メニュー、コーヒー……)。
- **汉字**从第 2 单元开始出现。含汉字的词条 187 个,全部填了 reading。其中**音读汉字词**(和中文同源、中国学习者能借字形理解的)84 个,去掉量词(時、分、円……)和七个星期,约 63 个,就是建议的“约 60 个常用汉字词”;其余是按日语习惯用 N5–N4 汉字写的和语词(食べます、高い、父)。汉字太难或日常多写假名的词先用假名写,alt 里给汉字(やさしい / 優しい、ぎょうざ / 餃子),学习者打汉字也判对。
- noteZh 重点写中国学习者的坑:同形异义(大丈夫、勉強、野菜、料理、上手、写真、信号、切符、大家、先生、安い、授業、趣味、喫茶店)、一字多读(人 ひと / じん / にん、水 みず / すい、大 おお / だい;熟字训 今日、明日、昨日、お土産)、长音和促音(びょういん / びよういん、きって / きて、ビル / ビール)、高低音(あ↘め 雨 / あめ↗ 糖)、和中文思路不同的助词搭配(電車に 乗ります / 電車を 降ります、友だちに 会います、N が 好きです)。

## 词汇量

- 423 个词条:假名字符 97 个(平假名 50、片假名 47),词和短语 326 个:名词 149、动词 39、形容词 35、数词和量词 26、固定说法 20、副词 18、助词 15、代词 14、连体词(この 等)4、感叹词 2、专有名词 2、连词 2。253 个词标了高低音核 pitch(拿不准的没标);第 1–2 单元的词带 roman。
- 动词的 text 用 ます 形(食べます),id 用辞书形罗马音(ja.taberu),noteZh 写辞书形和动词类别,方便以后学辞书形、て形时沿用同一个词条。
- 新课每课 8–10 个新词;假名课 12 个(10 个假名 + 2 个问候语 / 词,见文末);复习课 3–4 个;每课 3–4 个复习词(第一课没有)。
- 覆盖 JLPT N5 的主要话题:问候、自我介绍、家人、数字、饮食、购物、时间日期、交通、日常生活和爱好。N5 还有一半左右的词(身体、季节和天气、身边的物品、上 / 下 / 中、更多动词形容词)留给第 9–20 单元。

## 给写课同事的注意事项

1. **新词和大纲一致**(校验会查):想加词、换词,先改对应单元的大纲文件再写课,并告诉负责人;同一个词只教一次,后面的课放进 `reviewItems`。写完跑 `npm run validate -- --lang ja --only ja.a1u3 --strict`。
2. **只用学过的词**,`line.items` 要列全(复习词尤其要列)。下面这些不单立词条,直接用,items 标对应的词条:
   - 人名、地名等专有名词(リン・ユー、さき、けんた、ジウ、こばやし、たなか、もり、そら;杭州、東京、新宿、上野、浅草、さくら公園、江之岛)。国名里 中国、日本 是词条,韓国、タイ、アメリカ 等当专有名词直接用。
   - 活用形标原词条:V ます / ません / ました / ませんでした / ましょう / ませんか / たい / て形 → 动词词条;〜くない、〜かった、〜じゃない → 形容词词条;です / でした → `ja.desu`。名词 + します 的名词单独出现时(掃除と 洗濯を しました、日本語の 勉強)标对应的 〜します 词条。
   - 组合:何 + 量词(何時、何分、何歳、何人、何曜日、何色、何番線、何で)标 何 和量词两个词条;按规则组成的数(じゅういち、にじゅう、さんびゃく、せんごひゃく)标组成它的数字词条;お / ご 前缀不单立。
   - 假名课的认读行(あいうえお)items 列字符词条。
   - 语法说明里提到的说法(まだまだです、お名前は、〜てください 等)只放在 `grammar` 的例句里,不进课文。
3. **句子的写法**(练习直接拿课文出排序题和跟读题,课文里不能有错的日语)
   - **reading**:有汉字的句子必须写整句读音,全用假名;助词照写 は / へ / を(不改成 わ / え / お);数字按读法写成假名(3,200円 → さんぜんにひゃくえん)。
   - **roman**:第 1–2 单元每句都写。平文式罗马字,词与词之间空格,助词按读音写(wa / e / o),长音按假名写(ou、ei、uu,和输入法一致),促音双写辅音(kitte),ん 在元音或 y 前写 n'。第 3 单元起不写(学习者已经能读假名,罗马音会变成拐杖)。
   - **tokens**:每句都写,连起来必须等于去掉空格的原句。切法:词和助词分开,です / ます 等跟着前面的词,标点并进前一块,固定说法(おはようございます、ありがとうございます)不拆;一句 3–10 块,超过 10 块就拆成两句。例:わたしは リンです。→ ["わたし", "は", "リン", "です。"];7時に 起きます。→ ["7時", "に", "起きます。"]。
   - A1 每句不超过 30 个字(不算标点和空格,校验会查)。大纲例句为了好读在词之间加了空格;课文第 1–4 单元可以保留这种空格(分かち書き),第 5 单元起按正常日语不加。
4. **校验的硬性要求**:课文 4 句以上至少 2 道理解题;reading 至少 6 句,说话人用 `rin`(第一人称)或 `narrator`;每课 `scenarioZh` 末尾列了建议的说话人。
5. **礼貌体为主**:A1 所有人物对林雨都用 です・ます;朋友之间的简体只以固定说法出现(ありがとう、おはよう、おやすみ),写在 noteZh 里,课文不用。
6. **朗读**:助词词条 は / へ / を 单独朗读时要读 wa / e / o(系统朗读会读成 ha / he / wo,需要配音或在播放器里特殊处理);っ 和 ー 没有独立读音,字符卡的“听”可以换成例词。
7. **特别注意的课**
   - u1.l01–l05:每课只有两个词,对话 3–6 句即可;拗音、促音、长音的对比词(きって / きて、びょういん / びよういん)放在 grammar 例句里。
   - u2.l03:否定“不是……”u2.l05 才学,这一课否定回答只说 いいえ。
   - u3.l02:自己家人和别人家人的说法要成对对比;u3.l03:“电话号码”这个词 u3.l05 才教;u3.l04:4人 よにん、20 岁 はたち。
   - u4.l01:价格 u4.l02 才学,店员不报价格;u4.l04:好き / 嫌い 用 が,当面说 嫌い 太重。
   - u5.l03:面试时不用 アルバイト 这个词(u5.l05 才教);u5.l04:日期只用教过的(1–5 号、10 号和“数字 + 日(にち)”),6–9 号、14、20、24 号只在语法说明里出现。
   - u6.l03:指路不用 て形(u8.l05 才学),用“まっすぐです”“右に 曲がります”。
   - u7.l04:“人 に 买”(给某人买)第一次出现。
   - u8.l03:楽しかったです 先当固定说法;u8.l05 系统讲 て形 和 でした,只用学过的动词。

## 和最初建议不同的地方

- **假名课每课 12 个新词条**(10 个假名 + 2 个问候语 / 词),超过一般课 6–10 个的上限:46 个假名要在 5 课里教完,每课 10 个字符已经用满,再配两个词才能“学完能做一件事”。坚持 10 个以内,就只能把一部分假名挪到后面的单元,或者不给每个假名立词条(没有复习卡),两种都更糟。
- **数字提前**:0–10 在第 3 单元(报电话号码、年龄、人数),百 / 円 在第 4 单元(价格),千 / 万 在第 7 单元;第 5 单元只讲钟点、星期和日期,否则放不下。
- **汉字词的口径**:见“假名和汉字的安排”——音读汉字词约 63 个(不算量词和星期),含汉字的词条一共 187 个。
- **课号和顺序**:复习课 id 用 l08,order 按 id 算,和英、法、德大纲一致,以后每单元扩到 8 课也不用改 id。
- **文件**:按负责人的要求,大纲分成 8 个单元文件,没有单个的 `ja.json`。
- **角色**:除了 7 个固定角色,加了泛指的 `kurasumeito`(别科男同学),课堂场景需要别国同学说话。
