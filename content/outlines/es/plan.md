# 西班牙语课程单元规划(A1 20 单元 + A2 30 单元)

> 机器可读的规划在同目录的 `plan.json`(A1:第 1–8 单元新增的课 + 第 9–20 单元)和 `plan-a2.json`(A2 第 1–30 单元),格式相同。
> 规划只定每节课的标题、能做到什么(canDoZh)、场景和说话人(scenarioZh)、语法 / 发音重点(grammarFocusZh),**不登记词条**;写课前先把新词补进大纲(`es.json` 或 `es/` 下不以 plan 开头的文件)。
> 写课前还要看 `../es.md`(人物和写作约定)和 `../es.facts.md`(课文里已经定下的细节)。

课的类型:dialogue 175、grammar 96、vocab 81、reading 130。第 9–20 单元和 A2 每个单元的 l08 都是"单元复习与应用",是至少 12 句(A2 至少 14 句)的长对话。

## 顺序规则(写课时最容易出错的地方)

`lessons` 按学习顺序排列(和 `packages/core/src/hours.ts` 的 `orderFromId` 一致):

- A1:l01 l02 l03 l04 **r01** l05 l06 l07 l08 **r02**——r01 只能用本单元 l01–l04 和以前的词。
- A2:l01 l02 l03 **r01** l04 l05 l06 **r02** l07 l08 **r03**。
- **第 1–8 单元的 l06、l07 排在已经写好的 l08 前面**,所以不能用 l08 才登记的词:1-8 的 cero、el apellido、De nada、Hasta luego;2-8 的 el amigo、nosotros、ellos、joven;3-8 的 querido、un abrazo、la foto、tranquilo;4-8 的 pagar、la carta、el pan、la verdura;5-8 的 la semana、el año、la biblioteca、el gimnasio;6-8 的 volver、luego、nuestro;7-8 的 cambiar、la bufanda、el tique;8-8 的 porque、el pueblo、próximo。也不能用后面单元才学的词(scenarioZh 里标了几处,如 2-7 别用 restaurante、5-7 别用 para、6-7 别用 viajar)。

## 语法分布

原则:每个语法点**只在一个地方首次讲解**,之前出现时只当固定说法(grammarFocusZh 里写"先当固定说法记"),之后是复习和应用。grammarFocusZh 里的"复习 X-Y"指出了前后的联系。

### A1 第 1–8 单元新增的语法点

| 单元 | l06 | l07 |
|---|---|---|
| 1 | 更多国籍形容词(-és → -esa、-án → -ana,重音符号去掉)、el país | 接电话 ¿Sí? / ¿Diga?、电话里说 Soy + 名字 |
| 2 | 性格形容词(-or → -ora)、bastante + 形容词 | 职业名词的阴阳性(-ista 男女同形)、trabajar de |
| 3 | poner(pongo) | 楼层 el piso / la planta、el edificio |
| 4 | 容器 + de + 名词、No, nada más | ¿Me pasas…?(固定说法)、bien / mal 修饰动词 |
| 5 | la hora、时差、llamar a + 人(人称 a)、todos los + 名词 | la cita、una vez / dos veces(la vez) |

### A2 的语法进程

按"过去时 → 代词和命令式 → 将来时和其他 → 综合复习"推进,负责人列出的 14 个点都有专门的单元:

| 阶段 | 单元 | 首次讲解 |
|---|---|---|
| 简单过去时 | 1–3 | 规则全部人称和 llegué 类拼写变化;强变化不规则(fui、hice、tuve、estuve、pude、puse、vine、quise、dije);dar / ver、第三人称词根变化(pidió、durmió)、元音间 y(leyó);生平的时间表达 |
| 反身动词全面 | 4 | 日常、情绪变化(ponerse + 形容词)、相互(nos llevamos bien)、ir / irse 等成对动词、代词的位置 |
| 未完成过去时 | 5–6 | 规则和 ser / ir / ver;过去的习惯和 soler;描述(había、era、estaba)、antes / ahora、ya no / todavía |
| estar + 副动词 | 7 | 现在进行时、不规则副动词、代词位置;acabar de + 动词原形 |
| 两种过去时对比 | 8–9 | 背景和事件、cuando / mientras、iba a + 动词原形;estaba + 副动词 + cuando、讲故事的连接词 |
| 现在完成时 | 10–11 | 规则分词、hoy / esta semana、ya / todavía no;不规则分词、alguna vez / nunca、和简单过去时的分工、estar + 分词 |
| 礼貌条件式 | 12 | me gustaría、podría、querría、preferiría、¿sería posible…?、quería |
| 时间表达 | 13 | hace(……以前)、desde、desde hace、hace … que、durante、desde … hasta |
| 宾语代词 | 14–15 | 直接宾语全套(7-7 已经会 lo / la 指东西)和位置;间接宾语、a + 人、se lo |
| 肯定命令式 | 16–17 | tú / vosotros 和八个不规则形式、加代词;usted / ustedes;deber 和 deberías |
| 比较级和最高级 | 18 | tan … como、tanto … como、el más … de、-ísimo、mayor / menor、lo mejor / lo peor(más / menos … que、mejor、peor 在 A1 已学) |
| 将来时 | 19–20 | 规则形式和 ir a 的分工、预测;不规则词根、si + 现在时 + 将来时 |
| 关系代词 | 21 | que、donde、el que / la que |
| por 和 para | 22 | 两者的用法和对比、固定说法 |
| 补充的 A2 点 | 23–27 | alguno / ninguno;转述(dice que、pregunta si)和看法、interesar / molestar / apetecer 等;无人称 se;volver a、dejar de、seguir + 副动词和建议的说法;重读物主词 mío 和 el mío |
| 综合复习 | 28–30 | 三种过去时;篇章连接词和邮件格式;A2 总复习 |

A2 里否定命令式和虚拟式都不教(只用 ¡Que te vaya bien! 这类固定说法;要说"别……"用 es mejor no / no debes + 动词原形),cuando + 将来的事也避开。
