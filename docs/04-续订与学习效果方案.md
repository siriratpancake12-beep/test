# 续订与学习效果方案

> 2026-10-23 · 总负责人决策稿。目标:让付费用户一期接一期地续订,而续订的理由必须是"真的学会了"。

## 一、核心判断

用户每到扣费日,心里都会问一句"值不值"。答案取决于三件事,任何一件归零,他就会退订:

| | 用户心里的话 | 最常见的流失场景 |
|---|---|---|
| **看得见的进步** | "我确实比上个月强了" | 学了三个月还是开不了口、说不出学会了什么 |
| **养成的习惯** | "每天学一会儿已经是习惯了" | 出差、考试周断了几天,回来面对几百张积压的复习,干脆放弃 |
| **还没到的目标** | "离我的目标还差一点" | 目标太远看不到头;或者考完试目标没了 |

所以策略是**效果先行**:先把学习效果做实,再把效果"翻译"成用户能感知的东西;习惯和目标用来保护这个过程不被打断。**不靠套路**(难取消、偷偷续费、制造焦虑)——这些短期多收一个月,长期换来退款、投诉、差评和商店下架风险,得不偿失。

## 二、学习效果:六条学习科学原则 → 产品功能

| 原则 | 意思 | 我们的做法 | 代码 |
|---|---|---|---|
| 间隔复习 | 在快忘的时候复习,记得最牢、最省时间 | FSRS 算法排复习;一个词拆成"看懂、听懂、会写"三张卡分别安排 | `srs.ts` |
| 提取练习 | 自己想出来比反复看有效得多 | 每节课以练习收尾;产出类题目(写出来、选冠词)占一半,不只是选择题 | `exercises.ts` |
| 针对性练习 | 专门练自己最常错的地方 | 判题会说清错在哪(冠词、重音符号、大小写……),记录成弱点,每天安排专练 | `grading.ts` `learner.ts` |
| 合适的难度 | 正确率 75%–93% 时进步最快 | 正确率太高建议跳级,太低自动减少新内容、多复习 | `learner.ts` `plan.ts` |
| 可理解的输入 | 听得懂大部分的材料才学得进去 | 内容校验:课文只能用已经教过的词 | `validate.ts` |
| 即时、具体的反馈 | 马上知道错在哪、为什么 | 每题用中文解释,比如"冠词应该是 der,不是 die" | `ExerciseView.tsx` |

**这是和参考项目(泰好说)最大的不同**:它几乎只有"听音选图",一个词只有一张卡,判题只分对错。对中国人学德语、法语来说,最大的难点(名词的性、冠词、重音符号)恰恰需要"指出错在哪 + 集中练"。

## 三、让进步看得见

用户感觉不到的进步,对续订没有帮助。每一项都只用真实数据:

- **每节课写清"学完能做什么"**(`canDoZh`,内容校验强制要求),学完时打勾,周报里汇总"这周你学会了"。
- **能主动用的词**:看到中文能写出外语、而且已经记牢的词(不是"学过多少词")。刚学的、刚答错的都不算——数字小一点,但每一个都是真的。
- **错误改善**:"冠词的错误从上周 8 次降到 1 次"。专练和周报配合,让"弱点变强"被看见。
- **里程碑**:不只说"预计 2031 年达到 B1"(太远会泄气),而是"下一站 A1:预计 2027 年 10 月"。
- **等级进度条**:A1 课程 12/40。

下一步:每月一次阶段测评(固定难度的题,前后可比),给出 A1.1 → A1.2 这样的细分等级和可分享的证书(也是朋友圈传播的入口)。

## 四、保护学习习惯

| 机制 | 规则 | 代码 |
|---|---|---|
| 每日计划 | 打开就知道今天做什么、多久:复习 → 弱点专练 → 新课,总量按每日目标 | `plan.ts` |
| 学习提醒 | 在**他自己习惯的时间**提醒(按学习记录统计),只排未来 3 天,3 天没来就不再提醒 | `remind.ts` `notify.ts` |
| 连续天数 + 保护卡 | 连续学满 7 天送 1 张保护卡(最多 2 张),漏学一天自动用掉 | `habit.ts` |
| 轻松回归 | 离开 3 天以上,当天只安排最重要的复习,不学新课,"今天 X 分钟就好" | `plan.ts` |
| 复习封顶 | 每次复习量有上限,积压再多也不会一次压上来 | `plan.ts` `session.ts` |
| 按当地时间算天 | 出国后时区变了也不会断连续天数(留学用户的真实场景) | `time.ts` |
| 通知权限 | 学完第一课、尝到甜头之后才问,而不是一打开就要 | `lesson/[id].tsx` |

## 五、目标:一开始就对齐期望

新用户引导会问:为什么学、想到什么水平、每天多久、有没有期限、有没有基础(有基础就做分级测试跳过会的内容)。然后给出具体计划:

- "每天 15 分钟,预计 2027 年 10 月达到 A1、2031 年 12 月达到 B1"
- 有期限且来不及时直接说:"要在 2027 年 10 月前达到 B1,每天需要约 77 分钟",一键改成每天 80 分钟;超过 2 小时就建议先把目标降一级。

**为什么要说实话**:期望一开始就对,后面才不会"学了半年怎么还没到 B1"而失望退订、要求退款。学满 5 天后,预估改用他真实的学习节奏。

下一步:达到目标时自动建议下一个目标(比如 A2 → 考试专项),避免"目标达成 = 退订"。

## 六、付费设计

| | 免费 | 会员 |
|---|---|---|
| 分级测试、学习计划、每日提醒 | ✅ | ✅ |
| 第一单元全部课程 | ✅ | ✅ |
| **复习(永远免费)** | ✅ | ✅ |
| 周报:学会了什么、学习量、能主动用的词 | ✅ | ✅ |
| 全部课程 | | ✅ |
| 弱点专练 | | ✅ |
| 完整周报:听说读写能力、错误改善、下周重点 | | ✅ |
| (下一步)AI 口语陪练、发音评分 | | ✅ |

**几条规则**
- **复习永远免费**:不拿用户的记忆当人质。退订的人也能继续复习,记忆保住了,回来续订的理由也保住了。
- **付费墙只出现在"想继续"的时刻**:看完学习计划、学完免费单元、点了锁住的课或专练。不在学到一半时弹;主动介绍最多 3 天一次。
- **用他自己的数据说明价值**:"你最近在「冠词」上反复出错 → 会员每天有专项训练"、"按你的计划预计 X 月达到 A1"。
- **只写已经做好的功能**。没做好的不写进付费页(这也是苹果审核要求)。
- **价格、试用、自动续费、怎么取消写在按钮旁边**;扣费前 5 天和前 1 天提醒(《网络交易监督管理办法》第十八条要求在自动续费前 5 日显著提醒),试用转正同样处理。

**建议定价(待你确认)**:年度会员 ¥298(含 7 天免费试用,约 ¥24.8/月),月度会员 ¥45。
- 试用只给年度:愿意试用的人多半是认真想学的;年付让他们有足够的时间看到效果,一年只做一次续订决定,而月付一年要做 12 次。
- 不做终身会员:AI 口语、语音评测、新课制作都是持续成本,终身会员会让最忠实的用户变成亏损。
- 价格要上线后用 A/B 测试校准。

## 七、怎么衡量

| 类别 | 指标 | 说明 |
|---|---|---|
| **北极星** | 每周学习 ≥ 3 天的付费用户数 | 同时反映"在付费"和"在学习";只看收入会诱导套路,只看活跃会忽略付费 |
| 学习效果 | 复习正确率、每周新增"能主动用的词"、阶段测评提升 | 正确率长期 > 95% 说明太简单,< 75% 说明太难 |
| 习惯 | 次日 / 7 日 / 30 日留存;每周学习天数 | |
| 商业 | 试用开启率、试用转付费率、首次续费率、年度续费率、退款率 | 退款率和差评是"套路"的报警器 |

上线第一个月先测出基线,再定目标。所有指标需要服务器埋点(下一阶段)。

**要做的 A/B 测试**(按对续订的影响排序):付费墙出现的时机(看完计划 vs 学完第一课)、试用天数(7 vs 14)、价格、提醒文案、默认每日目标。

## 八、和参考项目对比

| | 参考项目(泰好说) | 我们 |
|---|---|---|
| 题型 | 几乎只有听音选图 | 选意思、听力、写出来、选冠词、句子排序、跟读;弱点专练 |
| 判题 | 对 / 错 | 对 / 基本对 / 错,并用中文指出错在哪 |
| 复习 | 一个词一张卡 | 一个词三张卡(看懂、听懂、会写) |
| 难度 | 固定 | 按正确率自动调节;分级测试跳过会的内容 |
| 进步感 | 家长报告(给家长看) | 能力清单、能主动用的词、错误改善、里程碑预估(给学习者自己看) |
| 习惯 | — | 每日计划、习惯时间提醒、保护卡、轻松回归 |
| 付费 | 没有 | 完整的订阅设计,合规提醒,复习永远免费 |

## 九、接下来做什么(按对续订的影响排序)

1. **服务器**:账号(手机号、微信、Apple 登录)、进度同步、订阅收据校验、埋点。没有它,真实付费和数据分析都做不了。
2. **内容**:英、法、德 A1 各约 40 课,母语老师审校,商用授权配音。这是最大的成本,也是效果的根本。
3. **口语**:跟读打分 → AI 角色扮演(只用学过的词、在剧本范围内)。"开不了口"是中国学习者的头号痛点,也是会员价值最强的感知点。
4. **阶段测评 + 证书**。
5. **目标达成后的下一目标、考试专项**(雅思、歌德、TEF/DELF)。
