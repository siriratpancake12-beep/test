## 三、源代码材料怎么准备

### 3.1 规则(按惯例)

- 提交源程序的**前连续 30 页和后连续 30 页**,共 60 页;整个程序不到 60 页的,全部提交。
- 每页不少于 **50 行**(最后一页除外)。
- 每页的页眉写软件名称和版本号(和申请表完全一致:语途外语学习软件 V1.0),并标页码。
- 第 1 页应当是程序的开头(入口文件),第 60 页应当是一个文件(模块)的结尾。
- 只提交我们自己写的代码:不放第三方库、开源代码、自动生成的文件;代码里不能有和著作权人不一致的版权声明或其他公司的名称。
- 不能出现密钥、密码、个人信息(本仓库的代码本来就不含密钥)。
- 提交的代码要和登记的版本一致:定版时打 git 标签,材料从这个标签导出。

### 3.2 选哪些文件、按什么顺序

按"App 入口 → 页面 → 组件 → App 公共模块 → 学习引擎 → 支付校验 → 服务器"的顺序,最后以服务器入口 `services/api/src/server.ts` 结尾:

1. `apps/mobile/src/app/_layout.tsx`(App 入口和页面导航)
2. `apps/mobile/src/app/` 下的其他页面
3. `apps/mobile/src/components/`
4. `apps/mobile/src/` 下的公共模块(本地存储、内容加载、提醒、购买、接口客户端等)
5. `packages/core/src/`(学习引擎:内容格式、判题、间隔复习、学习计划、会员订阅等)
6. `packages/billing/src/`
7. `services/api/src/`,最后是 `server.ts`

不放:`apps/mobile/src/content.generated.ts`(自动生成的内容索引)、`apps/mobile/src/legal/`(协议文本,不是程序)、测试代码、`content/` 下的课程 JSON、`node_modules`。代码注释里提到其他产品的地方(例如"参考项目")建议在定版时删掉,免得审查时产生误解。

### 3.3 操作步骤

在仓库根目录(定版的 git 标签上)运行:

```
# 1. 按顺序列出文件
{
  echo apps/mobile/src/app/_layout.tsx
  find apps/mobile/src/app -name '*.tsx' ! -name '_layout.tsx' | sort
  find apps/mobile/src/components -name '*.tsx' | sort
  find apps/mobile/src -maxdepth 1 \( -name '*.ts' -o -name '*.tsx' \) ! -name 'content.generated.ts' | sort
  find packages/core/src packages/billing/src -name '*.ts' | sort
  find services/api/src -name '*.ts' ! -name 'server.ts' | sort
  echo services/api/src/server.ts
} > /tmp/yutu-src-files.txt

# 2. 拼成一个文本文件:每个文件前加一行文件名,去掉空行
while read -r f; do echo "// ===== $f ====="; grep -v '^[[:space:]]*$' "$f"; done < /tmp/yutu-src-files.txt > /tmp/yutu-src.txt

# 3. 看总行数:超过 3000 行(60 页 × 50 行)就只取前 30 页和后 30 页
wc -l /tmp/yutu-src.txt
```

然后在文字处理软件里排版:A4 纸,等宽字体小五号(9 磅),行距固定值 12 磅,这样每页约 55 行;页眉"语途外语学习软件 V1.0",页脚页码。取第 1–30 页和最后 30 页,确认最后一页停在 `server.ts` 的结尾,导出 PDF。

# 语途外语学习软件 V1.0 用户手册

## 第一章 引言

### 1.1 编写目的

本手册介绍语途外语学习软件 V1.0(以下简称"本软件")的功能和操作方法,供用户使用本软件时参考,也作为本软件的设计说明。

### 1.2 软件简介

本软件是面向中文母语学习者的外语学习应用,首批支持英语、法语、德语,运行在 iPhone、iPad 和 Android 手机上。

本软件的设计思路是"效果先行":先根据用户的学习目的、目标水平和每天可以投入的时间,生成一份具体的学习计划,并如实预估达到目标的时间;再通过每日计划把复习、弱点专练和新课安排好;通过能指出具体错误的判题、按遗忘规律安排的复习和每周学习报告,让用户看见自己的进步。

### 1.3 适用对象

本软件面向 14 周岁以上、以中文为母语的外语学习者,包括零基础入门的学习者,以及为留学、移民、工作、旅行、考试或兴趣学习外语的学习者。

### 1.4 运行环境

- 手机系统:iOS 16.4 及以上,或 Android 7.0 及以上。
- 网络:课程学习、练习和复习可以离线使用;登录、学习进度同步、会员购买需要联网。
- 存储:课程内容随软件安装,学习记录保存在手机本地数据库中。

### 1.5 术语

- **CEFR 等级**:欧洲语言共同参考框架划分的语言水平,从低到高为 A1、A2、B1、B2 等。本软件的课程和目标都按这一标准划分。
- **单元、课**:课程按单元组织,每个单元包含若干节课。每节课都写明"学完能做什么"。
- **复习卡片**:每学一个词,本软件为它建立认读(看到外语想起意思)、听力(听到外语想起意思)、产出(看到中文写出外语)三张复习卡片,分别安排复习。
- **弱点**:用户在练习中反复出现的同一类错误,例如冠词用错、漏写重音符号。
- **保护卡**:连续学满 7 天赠送 1 张(最多存 2 张);某天漏学时自动使用,连续学习天数不中断。

## 第二章 功能总览

本软件由以下功能模块组成:

1. **新用户引导**:选择语言,设定学习目的、目标水平、每天学习时长和期限,选择是否有基础。
2. **分级测试**:有基础的用户逐级测试,跳过已经掌握的内容。
3. **学习计划**:显示达到目标的预计时间、各等级的里程碑,以及按期达到目标需要的每日学习时长。
4. **首页与每日计划**:显示今日学习进度、连续学习天数、今天的计划(复习、弱点专练、新课)、目标进度和全部课程。
5. **课程学习**:对话、生词、语法、练习四个环节。
6. **练习与判题**:选出意思、听音选意思、选择冠词、写出外语、句子排序、跟读六种题型,判为"答对了""基本正确""再记一下"三档,并用中文说明错在哪里。
7. **复习**:按遗忘规律安排今天要复习的词,每次的复习量有上限;复习永远免费。
8. **弱点专练**:针对用户最近反复出现的错误类型集中练习(会员功能)。
9. **每周学习报告**:这周学会了什么、学习天数和时长、新学的词和能主动用的词;会员可以看到听说读写各项能力和错误改善情况。
10. **学习习惯**:连续学习天数、保护卡、按用户习惯时间的学习提醒、离开几天后的轻松回归计划。
11. **会员**:会员介绍、免费试用、开通会员、恢复购买、管理订阅,以及扣费前 5 天和前 1 天的提醒。
12. **协议与隐私**:查看用户协议、隐私政策、自动续费服务规则、未成年人个人信息保护说明、第三方 SDK 清单和权限使用说明。
13. **账号与同步**(如 V1.0 已包含):手机号、Apple 账号或微信登录,多设备同步学习进度,注销账号。

### 3.6 首页

首页是用户每天学习的入口,从上到下依次是:

1. **今日进度**:例如"德语 · 今天 8/15 分钟",达到每日目标后显示对勾;下方显示连续学习天数和保护卡数量。
2. **提示**:根据学习情况显示,例如离开 3 天以上回来时显示"欢迎回来!今天先把最容易忘的 N 张卡复习一下";正确率偏低时提示"今天多复习、少学新的";学得很轻松时建议做跳级测试。
3. **今天的计划**:按"复习 → 弱点专练 → 新课"的顺序列出今天要做的事和预计分钟数。点击即可开始;完成的项目显示对勾;需要会员的项目显示锁形图标,点击后进入会员介绍。

### 3.8 练习题型和判题

本软件有六种题型:

1. **选出意思**:显示一个外语词或句子,从选项中选出正确的中文意思。点击外语可以听发音。
2. **听一听,选出意思**:自动播放发音,从选项中选出意思;可以点击"再听一遍"。
3. **选择正确的冠词**(德语、法语):显示名词和中文意思,从冠词中选出正确的一个,例如德语的 der、die、das。
4. **写出来**:显示中文,用户在输入框中写出外语,点击"检查"。
5. **把词排成句子**:显示中文意思和打乱顺序的词块,用户按顺序点击词块组成句子(点击已选的词块可以撤回),点击"检查"。
6. **跟读**:显示句子和中文,点击句子听发音,可以点击"慢速再听",大声跟读后点击"我读完了"。(如 V1.0 已包含发音评分:点击录音按钮跟读,本软件给出发音分数。)

每道题作答后,本软件显示判题结果,点击"继续"进入下一题:

- **答对了**:完全正确。写出来的题会同时显示标准写法并播放发音。
- **基本正确**:意思对了但有小问题,例如漏写重音符号、德语名词没有大写、长单词中一个字母拼错、用 ae/oe/ue 代替 ä/ö/ü。本软件算作答对,同时提示问题所在。
- **再记一下**:答错了,显示正确答案,并说明错在哪里,例如"冠词应该是 der,不是 die""名词要连冠词一起记"。

这些错误类型会被记录下来,用于安排弱点专练和生成学习报告。

## 第四章 设计说明

### 4.1 总体结构

本软件由三部分组成:

1. **手机客户端**:采用 React Native 和 Expo 开发,一套代码同时运行于 iOS 和 Android。负责界面、本地存储(SQLite)、本地通知、语音播放和购买流程。
2. **学习引擎**:用 TypeScript 编写、与界面无关的核心模块,手机端和服务器共用。包括内容格式定义与校验、判题、间隔复习、练习生成、学习计划、目标预估、分级测试、学习报告、学习习惯和会员订阅状态。
3. **服务器**:采用 Node.js(Fastify)和 PostgreSQL,提供登录、学习进度同步、订阅校验和使用统计等接口。手机端和服务器之间的接口在学习引擎中统一定义,两端共用。

### 4.2 课程内容格式

- 每种语言有一个"语言包",声明这种语言的文字、冠词规则、名词需要标注的信息(例如德语名词必须标注性别和复数)、常见考试和学习难点。
- 每节课是一个结构化的内容文件,包含课程等级、单元、"学完能做什么"、对话、新词、语法和预计时长。
- 内容发布前经过自动检查:每节课必须写明"学完能做什么";德语、法语名词必须连冠词书写并标注性别,冠词和性别必须一致;课文只能使用已经教过的词;对话的说话人必须在语言包的角色表中。

### 4.3 判题

判题模块把用户的输入和标准答案比较,结果分为"答对了""基本正确""再记一下"三档:

- 先统一大小写以外的标点、空格和引号的写法;
- 只差变音符号(如 é、ü)的,判为"基本正确",提示重音符号;
- 德语名词首字母没有大写的,判为"基本正确",提示大写;
- 用 ae、oe、ue、ss 代替 ä、ö、ü、ß 的,判为"基本正确";
- 较长的单词只有一个字母拼错的,判为"基本正确",提示拼写;
- 冠词错误的,判为"再记一下",并指出正确的冠词。

每次判出的问题类型记入学习记录,用于弱点分析。

### 4.4 间隔复习

本软件采用 FSRS 间隔复习算法,目标记忆保持率为 90%。每个词建立认读、听力、产出三张卡片,分别计算下一次复习的时间:答错记为"重来",基本正确记为"困难",答对记为"良好",答得又快又对(2.5 秒以内)记为"简单"。每天复习的数量按用户每日学习时长设定上限(平时约占每日时间的一半,离开多天回来时可以占满),避免积压。

### 4.5 学习计划和难度调节

- 每日计划按"复习 → 弱点专练 → 新课"的顺序排列,按每分钟约复习 5 张卡片估算时间,总量不超过用户设定的每日时长。
- 正确率保持在 75%–93% 时学习效果最好:近期正确率高于 93%,提示可以做跳级测试;低于 75%,减少新内容、增加复习。
- 离开 3 天以上回来时,当天只安排最重要的复习,不安排新课。

### 4.6 目标预估

本软件按各等级从零开始所需的累计学时(默认 A1 约 80 小时、A2 约 200 小时、B1 约 400 小时、B2 约 600 小时,语言包可以单独设定),结合用户已经完成的课程和每天的学习时长,计算达到每个等级的预计月份。最近两周学习满 5 天后,改用最近两周的实际平均学习时间计算。设定了期限的,计算按期达到所需的每日时长。

### 4.7 学习提醒

本软件统计用户在一天中各个小时的学习次数,取最常学习的时间作为提醒时间,只安排未来 3 天的本地通知,每次打开软件或学完后重新安排;提醒内容随学习状态变化,例如"有 N 个词快要忘了,现在复习最省力"。会员自动续费前 5 天和前 1 天,另外安排扣费提醒。

### 4.8 数据存储和同步

- 学习记录保存在手机本地的 SQLite 数据库中,离线可用;连续答题时 0.5 秒内只写入一次,软件切到后台时立即写入。
- 登录后,学习进度同步到服务器。多台设备的进度按以下规则合并,保证不丢失学习记录、合并结果与先后顺序无关:学过的课和词取并集;复习卡片取最后一次复习较晚的一张;每天的学习记录逐项取较大值;学习目标等设置取最近有学习活动的一份。
- 日期一律按用户所在地的时间计算。

### 4.9 会员和扣费提醒

会员状态包括试用、有效、宽限期、扣费重试、已过期、已撤销等,按应用商店的交易和通知更新,以服务器记录为准。每个账号只能试用一次。会员到期前 5 天和前 1 天提醒用户,已关闭自动续费的不提醒。复习功能对所有用户免费。

### 4.10 安全和隐私设计

- 学习功能不需要登录,学习记录默认只保存在手机上。
- 手机和服务器之间使用 HTTPS 加密传输;登录凭证保存在系统安全存储中;服务器密钥只保存在服务器环境变量中。
- 使用统计只记录操作类型,不记录用户输入的内容,在用户同意隐私政策之前不记录。
- 支持在软件内查看全部协议和隐私说明。

## 第五章 常见问题

1. **不登录可以用吗?** 可以。学习、练习和复习都不需要登录,学习记录保存在手机上。
2. **换了手机,学习进度还在吗?** (如 V1.0 已包含同步)登录同一个账号即可恢复;会员可以在会员页点击"恢复购买"恢复。
3. **为什么写对了却显示"基本正确"?** 通常是漏写了重音符号、德语名词没有大写或者拼错了一个字母,本软件算作答对,同时提示你注意。
4. **复习太多做不完怎么办?** 每天的复习量有上限,做完今天的部分就可以;离开几天回来时,本软件只安排最重要的复习。
5. **不开会员能复习吗?** 能。复习永远免费。
6. **怎么取消自动续费?** 在会员页点击"管理订阅",或在手机系统的订阅管理中取消;取消后会员可以用到到期。
