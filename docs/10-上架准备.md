## 二、App Store

### 2.1 名称和商标

- 首选:**语途**(语言之途:有目标、有里程碑)。
- 备选(都需要查商标):
  - **言途**:同样是"语言之途",字面更书面;
  - **语程**:语言的旅程、里程,呼应"下一站 A1"的里程碑设计;
  - **语航**:语言的导航,强调"有方向、有计划"。
- 查商标:在中国商标网(sbj.cnipa.gov.cn)"商标网上查询"里做近似查询,至少查第 9 类(可下载的应用软件)、第 41 类(教育、培训)、第 42 类(软件服务),建议这三类一起申请注册。【负责人办理】
- 同时检查:App Store 和各安卓商店有没有同名 App(App Store 的名称不能和别的 App 重复,确定后尽早在 App Store Connect 创建 App 记录占住名称)、域名、微信公众号和其他社交账号能不能注册。
- 名称要一致:App 图标下的名字(app.json 的 `name`)、商店名称、App 备案名称、软著的软件名称(简称)要对得上。
- 不建议用拼音 "YuTu" 作英文名:容易和"玉兔"(月球车,Yutu)混淆。海外区名称也用"语途",英文写在副标题里。

### 2.3 描述(中文)

写作规则:只写已经做好的功能;不用"最""第一""国家级"等绝对化用语(《广告法》);不承诺考试分数和学习效果;不写考试名称(考试专项还没做,而且雅思、托福等是别人的商标)。AI 口语陪练、发音评分上线后再按 2.5 末尾的段落补充。

```
语途:看得见进步的外语学习计划。

语途是为中文母语者设计的外语学习 App,目前提供英语、法语、德语入门(A1)课程。告诉我们你为什么学、想学到什么水平、每天能学多久,语途会给你一份具体的学习计划,并且如实告诉你:按这个节奏,大约什么时候能达到目标。

【先定目标,再定计划】
· 学习计划:按你的目标和每天的时间安排学习,预估达到每个等级的时间;来不及时直接告诉你每天需要学多久。
· 分级测试:学过一些?做个 3 分钟的测试,跳过已经会的内容。
· 每日计划:打开就知道今天学什么、要多久——先复习,再练弱点,最后学新课。

【学一课,会一件事】
· 每节课都写清"学完能做什么",从生活场景的对话学起:对话 → 生词 → 语法 → 练习。
· 点句子听发音,长按看中文。
· 多种题型:选意思、听音选意思、写出外语、句子排序、选冠词、跟读。

【错在哪,用中文讲清楚】
· 不只判对错:漏了重音符号、德语名词没大写、拼错一个字母,会算"基本正确"并提醒你;冠词错了,会告诉你正确的冠词。
· 弱点专练:针对你最近反复出错的地方(比如名词的性和冠词)专门练习。

【在快忘的时候复习】
· 用 FSRS 间隔复习算法,在你快要忘记的时候安排复习。

· 复习永远免费。

【让进步看得见】
· 每周学习报告:这周学会了做什么、学了多久、现在能主动用多少个词。
· 连续学习天数和保护卡:连续学满 7 天送一张保护卡,漏学一天也不会断。
· 在你习惯的时间提醒你学几分钟;离开几天再回来,只安排最重要的复习,轻松重新开始。

【免费和会员】

会员:全部课程、弱点专练、完整的每周报告(听说读写各项能力、错误改善情况)。

【订阅说明】
· 年度会员 ¥298/年,首次开通可免费试用 7 天;月度会员 ¥45/月。价格以 App 内显示为准。
· 确认购买后,费用从你的 Apple ID 账户扣除。除非在当前周期结束前至少 24 小时关闭自动续费,订阅会自动续期;续期费用在当前周期结束前 24 小时内扣除。
```

### 2.7 App 隐私(隐私营养标签)

按实际收集的数据逐项填写。语途**不追踪**用户(没有广告、没有第三方统计、不和数据经纪商共享),所以每一项"是否用于追踪"都选"否",也不需要弹 App 跟踪透明度授权。

| 数据类型 | 收集的内容 | 是否与身份关联 | 用途 |
| --- | --- | --- | --- |
| 联系信息 › 电话号码 | 手机号登录 | 是 | App 功能(登录、账号安全) |
| 标识符 › 用户 ID | 账号 ID、Apple / 微信登录标识 | 是 | App 功能、分析 |
| 标识符 › 设备 ID | 安装时随机生成的安装标识(不是设备识别码;保守起见按设备 ID 申报) | 是(登录后和账号关联) | 分析 |
| 购买项目 › 购买历史记录 | 订阅交易记录 | 是 | App 功能 |
| 使用数据 › 产品交互 | 使用统计(打开、完课、复习、查看会员页等)、同步到服务器的学习进度 | 是 | 分析、App 功能、产品个性化(学习计划和难度按学习记录调整) |
| 用户内容 › 音频数据 | 发音评分的录音 | 见下 | App 功能 |
| 用户内容 › 其他用户内容 | AI 对话输入的文字 | 见下 | App 功能 |

- 录音和 AI 对话:苹果对"收集"的定义是"传出设备,并且保存时间超过实时处理这次请求所需的时间"。如果我们和服务商都是处理完立即删除(服务商在合同里承诺不留存),可以不申报;**只要服务商会留存(哪怕短期用于排查问题),就必须申报**,选"与身份无关联"、用途"App 功能"。签服务商合同时确认这一点。【负责人决定】
- 不收集:位置、健康、财务信息、通讯录、浏览记录、搜索记录、敏感信息、诊断数据(目前没有接崩溃统计;以后接了要补"诊断")。
- 隐私政策网址填已备案网站上的页面。

### 4.2 数据安全表单要点

| 数据类型 | 收集 | 共享 | 说明 |
| --- | --- | --- | --- |
| 个人信息 › 电话号码 | 是 | 否 | 可选(选择手机号登录时);用途:账号管理、App 功能、防欺诈和安全 |
| 个人信息 › 用户 ID | 是 | 否 | 可选(登录时);用途:账号管理、App 功能、分析 |
| 财务信息 › 购买记录 | 是 | 否 | 用途:App 功能、账号管理 |
| 音频 › 语音或声音录音 | 是 | 否 | 可选;勾选"临时处理"(评分后立即删除);用途:App 功能 |
| 消息 › 其他应用内消息 | 是 | 否 | AI 对话文字;可选;勾选"临时处理";用途:App 功能 |
| 应用活动 › 应用内互动 | 是 | 否 | 使用统计、学习记录;用途:分析、App 功能、个性化 |
| 设备或其他 ID | 是 | 否 | 随机安装标识;用途:分析 |
| 应用信息和性能 | 否 | — | 目前没有崩溃统计;接入后要补 |

### 4.3 其他声明

## 五、构建和提交(eas.json)

`apps/mobile/eas.json` 有四个构建配置,命令在 `apps/mobile` 目录下运行(`npx eas-cli@latest …`):

| 配置 | 用途 | 命令 | 产物 |
| --- | --- | --- | --- |
| development | 开发版 App(带开发菜单,连电脑上的开发服务器调试;通知、录音、内购等原生功能要用它测) | `eas build --profile development --platform ios` / `android` | iOS 装在登记过的测试机上;安卓 APK |

| production | 正式版:App Store、TestFlight、Google Play | `eas build --profile production --platform ios` / `android`,然后 `eas submit -p ios` / `android` | iOS ipa;安卓 AAB |
| production-cn | 国内安卓商店 | `eas build --profile production-cn --platform android` | 安卓 APK(和 production 同一个签名) |

- **开发版需要先安装 expo-dev-client**:现在项目里没有装,App 负责人运行 `npx expo install expo-dev-client` 后才能打 development 包(eas.json 已经配好 `developmentClient: true`)。【团队】

- 第一次使用要运行 `eas init`,它会在 app.json 的 `extra.eas.projectId` 写入项目 ID(App 负责人提交)。
- `channel` 是给以后的 EAS Update(热更新)准备的;现在还没装 expo-updates,不影响构建。
