## 你负责的文件
第 {UNITS} 单元每单元新增的 4 节:l06、l07(核心课)和读物 r01、r02,共 {COUNT} 个课文件。每单元课的顺序:l01–l04、r01、l05、l06、l07、l08(已写好的单元复习课)、r02。
1. **大纲(词条登记)**:一个文件 content/outlines/{LANG}/{OUTFILE},格式照 outline.ts 的 Outline:`{ "lang": "{LANG}", "levels": ["A1"], "units": [ …这几个单元的 unit 条目,照 {LANG}.json 里的原样抄… ], "lessons": [ …你的 {COUNT} 节课… ] }`。每节课的 id、type、titleZh、canDoZh、scenarioZh、grammarFocusZh 照 plan;goalZh 一句话;unit 和已有的一样;skills 按类型填;order 用 orderFromId(id) 算;estimatedMinutes 填课写好后算出的值。
2. **课**:content/courses/{LANG}/ 下每节课一个文件,如 a1u3.l06.json、a1u3.r01.json。**已经写好的 l01–l05、l08 不要改**(有的同事可能还在改这几个单元的核心课;校验结果里别人的课有问题不用管,在报告里提一句)。

## 词条怎么定
- l06、l07 每课 6–10 个新词,读物新词 0–4 个。新词要是这个话题里高频、学了能马上用的词和固定说法(参考 {EXAM});{NOUNRULE}
- **核心大纲漏掉了几个高频词,请在合适的课里补上**:{HF}(先搜一下确实没登记过;放在话题合适、越早越好的课里)。
- **不要重复登记**:加新词之前先在 content/outlines/{LANG}.json 和 content/outlines/{LANG}/*.json 里搜一遍(按 id 和写法)。已经登记过的词(包括后面单元才教的)不能再登记:后面单元的词提前到这里,会打乱已经写好的课。已经学过的词当复习词用。
- id 用 `{LANG}.<词的小写拉丁写法,空格和撇号换成下划线>`,照已有 id 的起法;同一个词只有一个 id。
- reviewItems:每课 3–6 个前面学过的词,课文里要真的用到。

## 课文只能用学过的词
按上面的顺序,到本课为止学过的词 = 前面单元的全部词(核心课 + 你写的新增课)+ 本单元排在本课前面的课的新词 + 本课新词。r01 在 l04 后面,只能用到 l04 为止的词;r02 在单元最后,可以用本单元全部的词。人名、地名可以用。场景要用到还没教的词,就改写场景绕开,或者登记成本课新词(不能是后面单元已经登记的词)。
