## 每节课的要求
- **newItems 和你登记的大纲完全一致**(同样的 id、同样的数量)。
- **lines(课文)**:dialogue 8–12 句;vocab / grammar 6–10 句(可以是几段小对话或例句);复习课 l08 12 句以上;reading 8–14 句(speaker 用 narrator;第一人称的短文、短信、日记是哪个角色写的,speaker 就用这个角色)。说话人只用 cast 里的 id 或 narrator。{LEVELRULE}每课要有几句 3–10 个词的短句(用来出"排序"题)。每句的 items 列出这句用到的**已学词条 id**(本课新词 + 以前课的词)。{STYLE}
- **questions(理解题)**:每课 2–4 道(课文 4 句以上至少 2 道);{QRULE}正确答案位置要分散(不要总是第一个);explainZh 指出课文里的依据。
- **grammar**:核心课 1–2 个语法点,用中文讲清楚(对比中文、英语和中国学生容易犯的错),每个配 2–4 个例句(例句也只用学过的词);复习课总结本单元的语法;读物可以没有语法点。
- 词条的 noteZh 写给中国学习者的提示;ipa 给音标。
- 内容原创;人物设定照 {LANG}.md 和 {LANG}.facts.md,不要矛盾;不要写真实品牌和真实的人的信息;适合 14 岁以上,不出现酒类、烟草、赌博;电话号码等用虚构的。
- review 写 "draft"。

## 完成标准
- `npm run validate -- --lang {LANG} --only {ONLY}` 0 个问题(还没写的课会用大纲顶上,所以可以单独校验你的课)。
- 用 hours.ts 的 estimateLessonMinutes 看每节课的时长:核心课 18–30 分钟(写充分,不要为了压时长删句子),读物 10–20 分钟;太短说明课文或题目太少,要补。estimatedMinutes 填算出的值(大纲和课文件都要填)。
- 先写完一个单元(大纲 + 课)、校验通过,再写下一个单元。**每个文件单独写**,一次只写一个课文件,单次输出不要太长。

## 最后的报告(给负责人,简洁)
写了哪些课、新词总数、每课时长范围、校验结果、新定下的人物细节(写后面的课要保持一致的)、发现的规划问题。不要贴大段内容。
