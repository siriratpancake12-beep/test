## 逐课检查并直接改正
1. **外语**:地道、自然;语法、变位、配合正确;标点和书写习惯对;符合本级别(句长上限由校验器检查);称呼(你/您)按 {LANG}.md。{LANGCHECKS}
2. **音标 / 读音**:正确,和语言包的约定一致。
3. **中文**:翻译准确、是自然的大陆简体中文;noteZh 有用、不啰嗦;语法讲解没有错误或误导性的"规则",例句正确。
4. **理解题**:只有一个正确答案,能从课文里得出;干扰项合理;explainZh 正确;答案位置不要总在同一个位置(App 按文件顺序显示选项)。
5. **items**:每句的 items 列全这句里用到的已教词条(新词 + 以前学过的);一词多义时标对义项。
6. **人物和情节**:和 {LANG}.md、{LANG}.facts.md 一致,单元之间不矛盾。发现新定下的细节,写进报告。
7. **说话人**:第一人称的短文、信、消息是谁写的就用谁,不用 narrator(朗读按角色性别选声音)。
8. **本课的目标表达要让主角说出来**,不要只放在对方嘴里。
9. **适龄和安全**:适合 14 岁以上;不出现酒精、烟草、赌博;没有刻板印象;不出现真实名人、品牌;电话号码用虚构的。
10. **真实性**:当地的交通、办事流程、价格、营业时间等符合实际情况。

## 修改规则
- **不改任何 id**,不增删 newItems(数量和 id 必须和大纲一致)。可以改词条的 text、zh、音标、noteZh、例句;改了某个新词的 text 或 zh,把大纲(content/outlines/ 下登记这个词的文件)里同一个词条也改成一样的——用小范围的定点修改,不要整个文件重写。
- 改完的课把 `"review"` 设为 `"ai"`(课的顶层字段)。
- 不要把课改得更长(核心课 18–30 分钟、读物 10–20 分钟,用 hours.ts 的 estimateLessonMinutes 算;estimatedMinutes 同步)。
- 改完运行 `npm run validate -- --lang {LANG} --only {ONLY}`,必须 0 个问题。
- **不要执行任何 git 命令**(只读的也不要),不要运行 content:index。临时文件放在 {SCRATCHROOT}/{SCRATCH}/ 里。大文件分几次写,单次输出不要太长。
